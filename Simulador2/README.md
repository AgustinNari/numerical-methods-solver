# Dynamic Systems Simulator — React App

Interactive application for exploring one-dimensional, two-dimensional, and three-dimensional dynamical systems.

This application is part of the collaborative [Numerical Methods Solver](https://github.com/AgustinNari/numerical-methods-solver) repository and provides a separate React-based environment for studying differential equations and system behavior.

## Features

- Simulation of 1D, 2D, and 3D dynamical systems.
- Predefined mathematical models and custom equations.
- Configurable parameters and initial conditions.
- Interactive time-series and trajectory visualizations.
- Equilibrium point analysis for 1D and 2D systems.
- Phase diagrams and vector fields.
- Animated simulation results.
- Mathematical explanations and formulas.

## Tech Stack

- React
- JavaScript
- Vite
- Plotly
- Math.js
- KaTeX
- React Markdown
- Lucide React

## Getting Started

### Requirements

- Node.js compatible with the project's Vite version.
- npm.

### Installation

From this directory, install dependencies with `npm ci`.

Start the development server with `npm run dev`.

Vite will display the local application URL.

### Build

Generate a production build with `npm run build`.

## Project Scope

This application is an educational tool for exploring mathematical models and numerical simulation. It is separate from the main Python/Streamlit application included in the repository.
